# Libft

## Description

Libftは、C言語の標準ライブラリ関数や、文字列操作・連結リスト操作に使う関数を自作する課題です。
各関数の仕組みを理解し、今後のC言語の課題でも再利用できる静的ライブラリ `libft.a` を作成します。

ライブラリは次の3つのパートで構成されています。

- Part 1: 標準ライブラリ関数の再実装
- Part 2: 文字列操作や出力に関する追加関数
- Part 3: 単方向連結リストの操作関数

## Functions

### Part 1 - Libc functions

- `ft_isalpha` : 英字（a-z、A-Z）かどうかを判定します。
- `ft_isdigit`: 数字（0-9）かどうかを判定します。
- `ft_isalnum`: 英字または数字かどうかを判定します。
- `ft_isascii`: ASCIIコードの範囲内かどうかを判定します。
- `ft_isprint`: 表示可能なASCII文字かどうかを判定します。
- `ft_strlen`: 文字列の長さを返します。
- `ft_memset`: メモリ領域を指定した値で埋めます。
- `ft_bzero`: メモリ領域を0で埋めます。
- `ft_memcpy`: 指定したバイト数のメモリをコピーします。
- `ft_memmove`: メモリ領域が重なっていても安全にコピーします。
- `ft_strlcpy`: バッファサイズを考慮して文字列をコピーします。第3引数 sizeは、コピーできる文字数ではなく、dst バッファ全体のサイズ（'\0' を含めたバイト数）を指定する仕様です。
- `ft_strlcat`: バッファサイズを考慮して文字列を連結します。
- `ft_toupper`: 小文字の英字を大文字に変換します。
- `ft_tolower`: 大文字の英字を小文字に変換します。
- `ft_strchr`: 文字列から指定した文字を最初に見つけた位置を返します。
- `ft_strrchr`: 文字列から指定した文字を最後に見つけた位置を返します。
- `ft_strncmp`: 2つの文字列を指定した文字数まで比較します。
- `ft_memchr`: メモリ領域から指定したバイトを検索します。
- `ft_memcmp`: 2つのメモリ領域を指定したバイト数だけ比較します。
- `ft_strnstr`: 指定した範囲内で部分文字列を検索します。
- `ft_atoi`: 文字列を整数に変換します。
- `ft_calloc`: 指定した要素数とサイズのメモリを確保し、0で初期化します。nmemb はsize_tで0以上のため、!= 0のあとに> 0は不要です。
- `ft_strdup`: 文字列を複製した新しいメモリ領域を確保します。

### Part 2 - Additional functions

- `ft_substr`: 指定した位置から最大長までの部分文字列を作成します。
- `ft_strjoin`: 2つの文字列を連結した新しい文字列を作成します。
- `ft_strtrim`: 文字列の先頭と末尾から指定した文字を取り除きます。
- `ft_split`: 区切り文字で文字列を分割し、文字列の配列を作成します。
- `ft_itoa`: 整数を文字列に変換します。
- `ft_strmapi`: 各文字に関数を適用して新しい文字列を作成します。
- `ft_striteri`: 各文字のアドレスを関数に渡し、元の文字列を操作します。
- `ft_putchar_fd`: 指定したファイルディスクリプタに1文字を出力します。
- `ft_putstr_fd`: 指定したファイルディスクリプタに文字列を出力します。
- `ft_putendl_fd`: 指定したファイルディスクリプタに文字列と改行を出力します。
- `ft_putnbr_fd`: 指定したファイルディスクリプタに整数を出力します。

### Part 3 - Linked list

- `ft_lstnew`: 内容を保持する新しいリストノードを作成します。
- `ft_lstadd_front`: リストの先頭にノードを追加します。
- `ft_lstsize`: リストのノード数を返します。
- `ft_lstlast`: リストの最後のノードを返します。
- `ft_lstadd_back`: リストの末尾にノードを追加します。
- `ft_lstdelone`: 指定したノードの内容とノード自身を解放します。
- `ft_lstclear`: 指定したノード以降をすべて解放し、先頭ポインタをNULLにします。
- `ft_lstiter`: 各ノードの内容に指定した関数を適用します。
- `ft_lstmap`: 各ノードの内容に関数を適用し、新しいリストを作成します。

## Error Handling

標準仕様で未定義とされるケースや、課題で動作が明示されていないケースについて、一部の関数では独自の処理を実装しています。

- `ft_memcpy`: `n` が0の場合は `dest` を返します。memcpy はC標準関数で、NULLポインタを渡す動作は n == 0 でも未定義です。
- `ft_strdup`: メモリ確保に失敗した場合 `NULL` を返します。
- `ft_strjoin`: いずれかの引数が `NULL` の場合は、動的に確保した空文字列を返します。メモリ確保に失敗した場合は `NULL` を返します。課題にはNULL引数時の動作は明記されていません。

これらの処理は、標準関数の未定義動作をすべて防止するものではありません。

## Instructions


`Makefile` を使って静的ライブラリを作成します。

```bash
make
```

各ソースファイルには、動作確認用の main 関数をコメントアウトした状態で記述しています。

テストする場合は、対象ファイルの main 関数のコメントアウトを解除し、以下のようにコンパイルします。

```bash
cc -Wall -Wextra -Werror *.c libft.a -o test
./test
```

テスト後は main 関数を再びコメントアウトします。


Makefileの主なターゲットは次のとおりです。

- `make` または `make all`: `libft.a` を作成します。
- `make clean`: オブジェクトファイルを削除します。
- `make fclean`: オブジェクトファイルと `libft.a` を削除します。
- `make re`: ライブラリを削除して再ビルドします。

コンパイルには `-Wall -Wextra -Werror` を使用します。
